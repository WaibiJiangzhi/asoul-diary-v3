## 已验证

- `npm run check`：类型检查、静态检查、Workers 构建通过。
- `npm run build:pages`：静态构建通过，首页与示例页预渲染成功。
- `npm run test:records`：25 项业务测试、4 项表情与正文测试通过。
- `npm run test:storage`：12 项存储测试、3 项 Service Worker 测试通过，共计 44 项自动测试。
- 新兼容测试直接按旧数据库名称和结构预置卡片、记录、设置、照片、草稿及修订号，验证加载、图片字节、保存后重开及旧备份恢复；不借助新版恢复函数预置数据库。
- 大数据备份往返覆盖 120 张卡、15,936 条记录、1,152 张照片。
- `npm audit --omit=dev`：0 条已知告警。不是全面安全审计；此前开发工具链告警未在本轮升级处理。
- Git 跟踪文件名检查未发现环境文件、签名文件、local.properties、work 或 outputs 产物；常见私钥及令牌模式扫描未匹配。扫描不等于证明仓库历史从未包含敏感信息。
- 本地浏览器设置页确认版本为 V3.0，备份说明、反馈入口与示例生活入口正常显示；控制台未见 error。截图在忽略目录 `app/outputs/v3-release-settings.png`。

## 发布时仍需核对

- 本轮未提供生产网址，未确认线上部署版本、HTTPS、外部访问和线上更新流程。发布后必须在实际分享地址复核。
- 保持原站点来源。更换域名、协议或端口不会自动迁移 IndexedDB，需要用户导出再恢复。
- 尚未覆盖 Android/iOS 全部真机输入法、安装后离线、后台回收与长期使用情形。
- 构建仍有单块超过 500 kB 的体积提示，低端手机弱网首开需持续观察。

公开分享指向首页，用户可选择进入示例生活。后续每次发布保留旧兼容基线，涉及数据操作须重跑存储回归；不通过更换数据库或清空数据来规避升级问题。
