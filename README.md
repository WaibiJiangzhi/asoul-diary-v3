# Asoul一个魂生活日记 v3

一本为手机设计的温馨生活日记。它希望让记录变得足够简单：即使躺着，也能用很少的操作记下今天；每一次打勾和进度变化都有明确、舒服的反馈，也能慢慢看见自己的成长。

## 设计关键词

**A-SOUL 主题、温馨、日记、陪伴成长、手机端、操作简单、简洁。**

这些词是界面和功能取舍的共同标准：第一屏先呈现正在记录的内容，不用大段介绍占位置；装饰要像陪伴，而不能盖过记录；所有主要操作都应适合单手完成。

主题系统分为两层：整本日记可以选择贝拉红、嘉然粉、乃琳蓝，标题、按钮、选中状态、边框、浅色底和阴影会作为一套完整色阶同步变化；倒计时和进度卡还可以单独选择主题色，卡片内的日期、数字、进度条和按钮必须保持一致。

## 主要功能

- **今日**：在今天和明天之间切换，从常用事项一键添加，也可以手动写一件小事，完成后打勾即可。
- **成长**：记录倒计时和进度目标；支持选择 2026 嘉然动态表情，足迹可以附上一句话、查看或删除，结束后收入成长纪念册。
- **日记**：按天记录文字和照片，可以把当天选中的小事作为独立快照收进日记。
- **主题与数据**：日记纸支持贝拉、嘉然、乃琳三套完整主题色，也可切换 15 张收藏壁纸；数据保存在本机，支持完整备份、恢复和清空。

v3 使用独立的数据结构，不读取、不迁移 v2 数据。

## 项目结构

- `app/app`：页面入口与全局样式入口。
- `app/components/diary`：今日、成长、日记和设置等功能模块。
- `app/lib`：本地数据、日期、类型与默认值。
- `app/public`：PWA 图标、壁纸和动态表情等静态资源。
- `本地素材（不上传）`：原始素材仓库，已由 `.gitignore` 排除，不会上传 GitHub。

最外层的 `app` 是当前 Cloudflare Pages 使用的网页工程根目录；里面的 `app/app` 是框架约定的页面目录，两者用途不同。若以后调整部署根目录，可以再把网页工程整体提到仓库根目录；当前先保持线上构建路径稳定。

## 本地运行

双击项目根目录的 `启动v3.cmd`即可构建并打开本地网页。开发时也可以在 `app` 目录执行 `npm run dev`。
