# 一个魂日记 · V3.0

一个以 A-SOUL 为主题、陪伴自己慢慢成长的手机 PWA，当前版本为 `3.0.0`，另提供安卓工程。

**温馨、陪伴成长、反馈感强、手机端、操作简单、简洁。**

打开就是「生活」：上方放陪伴自己的话或倒计时，下方记录正在做的事；以后想做的事情可以先收起。已经做成或想告一段落的经历，主动收进「纪念册」。

- **记录卡**：首页直接记录每天状态，展示最近七天；详情有日历、圆环与历史，支持补记。
- **进度卡**：积累里程、时长等数量，可以设目标，也可以一直记录。
- **阶段卡**：拆成几步，独立完成或重新打开，不强制按顺序。
- **随记卡**：先写文字、放照片，之后也能更换记录方式。
- 常用卡片可自行增删、修改，勾选后批量添加到生活；默认提供作息、跑步、旅行和画画。纪念册可再来一期，不复制旧记录和照片。
- 单层分组可筛选生活和纪念册，支持改名、排序；删除分组只将卡片移回未分组。
- 分组栏的日历图标可筛选「每日记录」：记录卡默认加入，其他卡可自行开启；当天未记录优先，已记录保留，可与分组叠加。
- 首页四类卡统一展示最近记录状态；阶段卡的经过天数保留在详情中。
- 四种卡共用文字、表情和照片记录。更换方式保留已有内容；每次达成、撤回后重新达成都有反馈。
- 保留三套主题色、温馨纸张、27 张壁纸，以及 18 套共 390 个表情；含 2026 乃琳酒馆动态表情 20 张。新用户默认使用第一张嘉然壁纸。
- 四种卡均可设期待日期；到期仍能继续记录，不会自动归档。陪伴卡优先展示当天的倒计时，其次是明天，同一优先级内随机选择。
- 纪念册保存整张卡和过程，可以恢复继续，也可以保留旧纪念再开一期。

## 本地使用

安卓工程的构建、安装与数据迁移说明见 [docs/android.md](docs/android.md)。网页版与安卓版本使用独立的本机数据，可通过完整备份迁移。

工程位于 `app`。双击根目录的 `启动v3.cmd`，或在 `app` 执行 `npm run dev`。

访问 `/preview` 可体验一段示例生活，包括四种生活卡、当天与未来的倒计时、纪念册和可查看的示例插画。日期跟随当天，修改仅在内存中，刷新即重置，不替换自己的记录。

数据只存浏览器本机 IndexedDB；文字保存为结构化记录，照片以 Blob 单独保存，记录内存照片 ID。完整 JSON 备份把照片编码成 Base64 一并带走。设置里可以下载、恢复备份。备份包含已确认记录和照片，不包含未提交草稿。

记录草稿（含待添加照片）独立保存在本地，关闭面板或刷新后再进入可继续编辑；确认后计入记录并清除草稿，恢复备份或清空数据也会清除草稿。示例页草稿只在内存中。

有记录后每隔 30 天显示一句备份提醒，点「知道啦」后重新计时；示例页不显示。不自动备份或上传数据。

沿用数据库 `asoul-life-v3-preview`，名称保留以兼容已有 V3 记录；应用版本号与数据格式版本独立。后续更新须兼容已有 V3 数据与备份，结构变化通过迁移处理。V3 之前的旧版数据库原样保留，不自动迁移。

## 开发与素材

- `npm run check`：类型、代码检查与 Workers 构建。
- `npm run build:pages`：Cloudflare Pages 静态构建。
- `npm run test:records`：记录规则、状态撤回、类型切换与表情。
- `npm run test:storage`：保存冲突、备份恢复、照片事务、离线缓存。
- `npm run fixture:sample`：生成 `fixtures/life-sample-backup.json`；导入会替换本机记录，日常看示例优先用 `/preview`。
- `npm run stickers:import`：从本地原件生成网页表情，自动使用 `gif` 目录的透明素材，保留 GIF 动画。
- `npm run wallpapers:optimize`：将壁纸目录内的 JPG/PNG 转为 WebP。

原始素材放在 `本地素材（不上传）`，由 Git 忽略；网页资源在 `app/public`。框架生成目录和缓存不属于源码。

两套 Cloudflare 构建继续保留。新版本准备好后由用户决定刷新；刷新前先保存。架构边界见 `docs/architecture.md`，项目约定见 `AGENTS.md`。
